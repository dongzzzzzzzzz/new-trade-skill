# Darwin 分阶段进化协议

## 目标

进化真实目标 skill 的选股过程，不建立一个脱离 skill 的外置排序器。

## 固定流程

```text
T 日事实
→ 指数环境
→ 接力情绪
→ 赚钱模式
→ 主线/分支
→ 节点与角色
→ 候选池
→ 原始队列
→ T+1 竞价验货
→ T+1 开盘买入
→ T+2 竞价卖出
```

## Challenger 规则

每轮只改一个步骤：

- 环境：只改变指数环境的事实解释；
- 情绪：只改变接力情绪的定义；
- 模式：只改变赚钱模式识别；
- 主线：只改变题材归并、主线和分支判定；
- 分歧孤立高位锁定：只改变分歧环境下高位单票缺少T日扩散时的主线、节点和候选准入；
- 双分歧高低切：只改变环境与接力情绪同时分歧时，非市场核心4至6板与同题材低位前排的角色和候选生成；
- 涨停开盘可达性：只改变 T+1 执行门；开盘达到涨停价且无法证明可成交时，按冻结队列顺延，不改变 T 日候选和队列；
- 节点：只改变穿越、断板、爆量、破局、补涨、卡位的识别；
- 候选池：只改变纳入、剔除和角色分配；
- 候选池完备性：只改变原始队列冻结前的漏选回查和上游回退条件；
- 竞价：只改变 T+1 09:25 前的验货和递补条件。

改变上游步骤后，必须重新生成所有下游结果。不能固定原候选池再重新排序，并把结果称为选股逻辑进化。

## 评估记录

每个案例记录：

1. 环境判断及证据；
2. 情绪判断及证据；
3. 赚钱模式；
4. 主线/分支/孤立异动；
5. 节点和候选角色；
6. 原始候选池和队列；
7. 竞价后保留和递补队列；
8. 实际执行股票；
9. T+1 开盘买入价；
10. T+2 竞价卖出价；
11. 失效原因和漏选原因。

## 禁止事项

- 不把板位、封单或竞价单一变量当成完整选股逻辑。
- 不用固定候选池证明主线识别已经进化。
- 不用 T+1 盘中、收盘或 T+2 之后的信息改写 T 日判断。
- 不把 T+1 开盘到 T+1 收盘当作真实可卖收益。
- 不打开 2026-09 至 2026-10-09 的封存数据进行调参。
