# 收益验证口径

## 实际交易时序

```text
T 日盘后：生成方向和原始候选队列
T+1 09:25 前：竞价确认
T+1 开盘：买入
T+2 竞价：卖出
```

## 单笔收益

```text
return_pct = (T+2_auction_sell_price / T+1_open_buy_price - 1) * 100
```

不能使用 T+1 收盘价作为卖出价，也不能把 T 日收盘到 T+1 开盘的跳空收益冒充可实现收益。

## 汇总指标

- 累计收益：所有实际执行交易的单笔收益相加；
- 胜率：`return_pct > 0` 的交易数 / 总交易数；
- 复利收益：按信号日期顺序，将每笔 `return_pct` 依次乘入权益曲线；
- 最大权益回撤：上述顺序权益相对历史权益高点的最大跌幅，用于比较策略版本的交易序列风险；它不等于单笔盘中最大不利波动；
- 最大不利波动：T+1 买入后至 T+2 竞价前的最低价格相对买入价；
- 空仓日：没有满足竞价条件的候选，不计入交易胜率，但必须记录；
- 漏选记录：候选池中事后表现明显更好的股票，以及它在原始判断中被排除的步骤。

## 数据边界

收益字段只能进入结果表，不能回流到 T 日和 T+1 09:25 前的输入事实。
